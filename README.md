Aplicação web desenvolvida em **React** para cadastro e gerenciamento de tarefas.

## Descrição / Visão Geral

O projeto foi criado com o objetivo de desenvolver uma aplicação simples e funcional para organizar tarefas do dia a dia.

Com a aplicação, o usuário pode:

- Cadastrar novas tarefas
- Informar o nome da tarefa
- Definir uma data
- Adicionar uma descrição
- Escolher o nível de prioridade
- Marcar tarefas como concluídas
- Reabrir tarefas concluídas
- Excluir tarefas
- Filtrar tarefas por status
- Manter as tarefas salvas no navegador utilizando `localStorage`

O projeto também foi desenvolvido para praticar conceitos importantes do **React**, como Hooks, estados, eventos, callbacks e métodos de manipulação de arrays.

## Tecnologias (Stack)

As principais tecnologias utilizadas no projeto são:

- **React** — criação da interface e dos componentes
- **JavaScript** — lógica e funcionamento da aplicação
- **HTML/JSX** — estrutura dos elementos da página
- **CSS3** — estilização e layout
- **Vite** — ferramenta utilizada para criação e execução do projeto React
- **Lucide React** — biblioteca utilizada para os ícones
- **LocalStorage** — armazenamento das tarefas no navegador

### Conceitos de React utilizados

O projeto utiliza:

- `useState` para controlar os dados da aplicação
- `useEffect` para salvar automaticamente as tarefas
- `map()` para exibir as tarefas
- `filter()` para remover e filtrar tarefas
- Callbacks para responder às ações do usuário
- Eventos como `onClick`, `onChange` e `onSubmit`

## Pré-requisitos e Instalação

Antes de executar o projeto, é necessário ter instalado:

- **Node.js**
    ### Como instalar o Node.js

    #### Pelo site oficial (Recomendado)
        1. Acesse o site oficial do [Node.js](https://nodejs.org).
        2. Baixe a versão **LTS** (mais estável e recomendada para a maioria dos usuários).
        3. Execute o instalador baixado e siga as instruções na tela.
- **Visual Studio Code** ou outro editor de código

### Clone o repositório

```bash
git clone https://github.com/AnaSBeaa/Lista-Tarefas.git
```

- **npm**

Depois de instalar o Node e clonar este repositório, navegue até a pasta do projeto e execute o comando abaixo para instalar todas as dependências necessárias:

```bash
npm install
```
